# 小山市 防災マップ (Oyama City Disaster Prevention Map)

栃木県小山市を対象とした、**「Jamstack型 Web GIS（静的配信 × ブラウザ空間演算）」** による軽量・高耐久・セキュアな防災地図Webアプリケーションです。

国土地理院・国土交通省の公式オープンデータ（指定緊急避難場所、洪水浸水想定区域タイル）を活用し、台風・豪雨などの災害時アクセス集中でもサーバーダウンしない高い可用性と、ゼロメンテナンスな運用性を実現しています。

---

## 📌 プロジェクトの背景とアーキテクチャ設計

### 1. 背景と課題
当初は「GeoDjango × SpatiaLite」を動かす構成で検討しました。しかし、利用環境下で以下の課題があり諦めました。：
- **ライブラリ依存問題**: root権限のない共用サーバーで、`GDAL` / `GEOS` / `PROJ` / `SpatiaLite` といった巨大なC言語ライブラリを手動ビルド・保守し続けるのは難度が高く、サーバーOSのアップデート等で動作不能になるリスクが高い。
- **高負荷・ダウンのリスク**: 防災アプリは豪雨や地震の最中にアクセスが集中します。動的バックエンド（Python CGI/Passenger）やデータベースクエリは、同時アクセス急増時にプロセス枯渇やDBロックでサーバー停止を引き起こす恐れがある。

### 2. 採用した解決策：Jamstack型 Web GIS
小山市内の指定避難所は全74施設（GeoJSONにしても約42KB）という軽量データです。
そのため、**「GIS処理や重いデータ加工はローカルDockerで完了させ、本番サーバーは静的配信（HTML/JS/GeoJSON）に徹する」** アーキテクチャを採用しました。

```
【ローカル開発 (Windows + Docker)】
  国土地理院ベクトルタイル (skhb01〜skhb08)
         ↓
  Python データ前処理パイプライン (data_pipeline/fetch_shelters.py)
         ↓
  最適化 GeoJSON 生成 (shelters.geojson: 74施設, 約42KB)
         ↓ Vite ビルド (npm run build)
  成果物ディレクトリ (dist/)

【本番環境】
  静的ファイル配信のみ (Apache / Nginx 等) 
  ※ .htaccess によるブラウザキャッシュ・Gzip圧縮・MIMEタイプ最適化
  ※ さくらのレンタルサーバを想定

【利用者のブラウザ (スマホ・PC)】
  ┌─────────────────────────────────────────────────────────┐
  │ Leaflet.js (高速な地図・レイヤーレンダリング)           │
  │   ├── 背景地図       : 地理院地図 (標準 / 写真 / 淡色)  │
  │   ├── ハザードレイヤー: 重ねるハザードマップ (洪水浸水想定)│
  │   ├── 避難所ピン表示 : shelters.geojson (74箇所)        │
  │   └── 空間演算 (Turf.js): 最寄り避難所検索・距離計算     │
  └─────────────────────────────────────────────────────────┘
```

#### 本構成のメリット
- 🛡️ **セキュア**: サーバー側でスクリプトやSQLを実行しないため、SQLインジェクションやサーバー侵入リスクが根本的にゼロ。
- ⚡ **災害時の高耐久性**: Webサーバーが静的ファイルをキャッシュ配信するのみ。数万PV/秒の集中アクセスでもたぶん落ちない。
- 🛠️ **メンテナンスフリー**: サーバー側の仕様変更に比較的影響を受けず、壊れない。
- 🚀 **超高速レスポンス**: ブラウザ側（Turf.js）で最寄り計算やフィルタリングを行うため、たぶん待ち時間0ミリ秒で動作。

## 🌟 主な機能

1. **洪水浸水想定区域のリアルタイムオーバーレイ**
   - 国土地理院「重ねるハザードマップ」のシームレスタイル（思川・巴波川・姿川・鬼怒川などの想定最大規模降雨）をLeaflet上に直接オーバーレイ。
   - 不透明度スライダー（10%〜100%）および浸水深の分かりやすいグラデーション凡例（0.5m未満〜10m以上）付き。
2. **小山市指定緊急避難場所（74施設）の完全網羅**
   - 国土地理院公式ベクトルタイルから最新データを抽出。
   - 施設ごとの対応災害（洪水、地震、土砂災害、火災、内水氾濫）をタグ表示。
3. **災害種別フィルター**
   - 「🌊 洪水対応」「🏚️ 地震対応」「⛰️ 土砂災害対応」「🔥 火災対応」「🌧️ 内水氾濫」をワンタップで切り替え、小山市内の避難所ピンを即時絞り込み。
4. **「🎯 最寄りの避難所」ワンタップ検索 & ハイライト機能**
   - ヘッダーのオレンジボタンを押すだけで、**「現在選択中のフィルター条件（例: 洪水対応）」に合致する最寄りの避難所** を瞬時に特定。
   - **ハイライト波紋アニメーション**: 最寄り避難所ピンの背後にオレンジ色の波紋パルスが広がり、地図上で一目で分かる。
   - **詳細ポップアップの自動オープン**: 施設名、住所、直線距離、徒歩目安、Googleマップ道順リンクを展開。
   - **点線ルート描画**: 現在地から最寄り避難所への直線ルートを表示。
   - **自動ズーム**: 現在地と最寄り避難所が両方画面に収まるよう自動調整。
   - **フォールバック機能**: PC等のGPS非搭載環境や位置情報が無効な場合でも、小山市役所を基準地として検索できる安心設計。
5. **避難所周辺の空間クロス集計情報（防災サマリー表示）**
   - 避難所ピンをタップした際に、その避難所の周辺インフラを自動集計してポップアップ内に表示：
     - ⚡ **AED設置情報**: 施設内常設の有無（職員室、保健室等の設置位置・小児対応フラグ）、または最寄りAED施設・直線距離
     - 🏥 **最寄りの医療機関**: 病院/診療所種別、直線距離、徒歩目安時間、電話番号
     - 🚻 **近隣の公衆トイレ**: 直線距離、徒歩目安、バリアフリー設備（♿車椅子、👶乳幼児、🚾オストメイト対応バッジ）
     - 🌳 **近隣の待避公園**: 公園名、公簿面積（㎡）、直線距離、徒歩目安時間
6. **周辺インフラのレイヤー重畳（フェーズフリー対応オープンデータ）**
   - 上部バーやレイヤーコントロールから、以下の施設ピンをワンタッチで表示/非表示切り替え：
     - ⚡ **AED設置場所（176施設）**: 市役所・学校・公共施設・民間等の設置位置、利用可能時間、小児対応設備
     - 🏥 **医療機関（138施設）**: 病院・クリニックの種別、診療科目、病床数、電話番号
     - 🚻 **公衆トイレ（115施設）**: バリアフリー設備（車椅子・乳幼児・オストメイト）の詳細
     - 🌳 **公園施設（351施設）**: 一時避難や車中待避に使える公園の公簿面積・位置
7. **背景地図の切り替え**
   - 地理院標準地図、淡色地図、航空写真（オルソ）の3種類を切り替え可能。
8. **緊急連絡先・公式リンクモーダル**
   - 小山市役所、小山市危機管理課、消防署（119）、警察署（110）、小山市防災ポータルへの直通リンク。

## 🚀 ローカル開発環境の立ち上げ手順 (Windows 11 + Docker)

### 1. Dockerコンテナの起動
リポジトリ直下で以下を実行します：

```bash
docker compose up -d
```

### 2. ブラウザでアクセス
👉 **[http://localhost:5173/](http://localhost:5173/)**

※`frontend/vite.config.js` に `watch.usePolling = true` が設定されているため、ホスト側（Windows）でファイルを編集・保存すると、コンテナ内のViteが検知してブラウザが自動でホットリロード（即時反映）されます。

### 3. コンテナの停止
```bash
docker compose down
```

## 🔄 オープンデータの更新手順（小山市データが更新された場合）

小山市のオープンデータや国土地理院の避難所情報が新年度等に更新された場合、以下の **3ステップ（コマンド3行）** で本番サイトを最新化できます。

```
[小山市公式オープンデータ / Code for OYAMA API]
                    ↓ (1) 取得・空間クロス集計
         [public/data/*.geojson]
                    ↓ (2) フロントエンド静的ビルド
                 [dist/]
                    ↓ (3) 本番サーバーへ転送
            [さくらのレンタルサーバ]
```

### ステップ 1: データの最新化（全自動パイプライン実行）
Code for OYAMA公式API（`https://api.code4oyama.org/v1.0/`）および国土地理院から最新データを一括取得し、避難所の空間クロス集計を再計算します：

```bash
docker compose run --rm data-pipeline
```
*(ホスト環境にPythonがある場合は `python data_pipeline/fetch_shelters.py` でも即時実行可能です)*

> [!TIP]
> **API連携とフォールバック**  
> 通常は `Code for OYAMA API` から高速・型安全に最新JSONを取得します。万が一APIサーバーがメンテナンス等で停止している場合は、小山市公式HPのCSVダウンロードへ自動フォールバックする耐障害設計になっています。

### ステップ 2: フロントエンドの再ビルド
更新されたGeoJSONを取り込み、公開用ファイルを生成します：

```bash
cd frontend
npm run build
```

### ステップ 3: 本番サーバーへのデータ反映
`frontend/dist/data/` フォルダ（または `dist/` 全体）をさくらのレンタルサーバへアップロードします：

```bash
# rsyncで反映する場合の例
rsync -avz --delete frontend/dist/data/ sakura-user@sakura-user.sakura.ne.jp:www/bousai/data/
```
※ファイルマネージャーをご利用の場合は、さくら管理画面で `frontend/dist/data/` 内の `.geojson` ファイルを上書きアップロードするだけで完了です。

## 🚢 本番環境（さくらのレンタルサーバ）へのデプロイ手順

### ステップ 1: ビルドの実行
ローカル環境で本番用静的ファイルをビルドします：

```bash
cd frontend
npm run build
```
実行後、`frontend/dist/` 配下に最適化されたファイル群が生成されます：
- `index.html`
- `assets/` (圧縮されたJS・CSS)
- `data/shelters.geojson` (小山市の避難所データ)
- `.htaccess` (キャッシュ・MIMEタイプ設定)

### ステップ 2: ファイルのアップロード
`frontend/dist/` 配下の全ファイルを、さくらのレンタルサーバの公開ディレクトリにアップロードします。

- **公開先URL例**: `https://<あなたのドメイン>/bousai/`
- **サーバー上の配置先**: `~/www/bousai/`
- **アップロード方法**:
  - **ファイルマネージャー**: さくらの管理画面から `frontend/dist/` の中身をドラッグ＆ドロップ
  - **SCP / SFTP / rsync**:
    ```bash
    rsync -avz --delete frontend/dist/ sakura-user@sakura-user.sakura.ne.jp:www/bousai/
    ```

サーバー側での Apache / Nginx / PHP / Python の追加設定は不要です。アップロードした瞬間に本番稼働します。

## 📜 使用オープンデータ・クレジット

本アプリは、以下の公的オープンデータを組み合わせて活用しています。

| データ名 | 作成・提供元 | 配信・連携基盤 | 内容・備考 |
| :--- | :--- | :--- | :--- |
| **指定緊急避難場所・指定避難所データ** | **栃木県小山市** | 国土地理院（指定緊急避難場所オープンデータ基盤 / ベクトルタイル `skhb01`〜`skhb08`） | 災害対策基本法に基づき小山市が指定・公開した公式避難所データ（全74施設、対応災害種別フラグ含む）。 |
| **AED設置場所一覧** | **栃木県小山市** | 小山市公式オープンデータ（市有施設・公共・民間AED一覧 / Code for OYAMA連携） | 小山市内のAED設置場所データ（全176箇所、設置位置、小児対応有無、利用可能時間等）。 |
| **医療機関一覧** | **栃木県小山市** | 小山市公式オープンデータカタログ (code=508) | 小山市内の病院・診療所データ（全138施設、診療科目、病床数、電話番号等）。 |
| **公衆トイレ一覧** | **栃木県小山市** | 小山市公式オープンデータカタログ (code=482) | 小山市内の公衆トイレデータ（全115施設、車椅子・乳幼児・オストメイト等設備情報）。 |
| **公園施設一覧** | **栃木県小山市** | 小山市公式オープンデータカタログ (code=634) | 小山市内の都市公園データ（全351施設、公簿面積等の待避空間情報）。 |
| **洪水浸水想定区域（想定最大規模）** | **国土交通省 / 栃木県** | 国土地理院（重ねるハザードマップ ラスタタイル） | 思川、巴波川、姿川、鬼怒川等の国・県管理河川シームレス氾濫シミュレーションタイル。 |

> [!NOTE]
> **避難所データの原典について**  
> 避難所の指定およびデータ管理の主体は **「栃木県小山市」** です。国土地理院は各自治体が指定したオープンデータを全国統一フォーマットで集約・配信しており、本アプリは小山市が公式に指定した避難所情報を取得・表示しています。
